# NPC 与怪物

给主持人现场查阅和朗读。事实与数值要能追溯到原文；缺失内容写【待补】并登记 Q 编号。性格分析可以依据行为、对白、经历、关系和目标作有根据的推断，但要注明推断依据，不能把推断写成原文事实。PDF 文件页码与印刷页码分开记录。

## NPC 三份汇总

| 文件 | 装什么 |
| --- | --- |
| `模组名 NPC人设.md` | 六字段 + 五场景台词 + 各形态客观外貌 |
| `模组名 NPC数据.md` | 属性、HP、AC、攻击、技能、装备等数值 |
| `模组名 NPC任务与地点.md` | 在哪出现、要玩家做什么、给什么、条件与状态变化 |

三份两两互相链接，标题统一写【N002 港务官哈维尔】。不按人物或形态拆文件。

来源标注到文件、章节或页码。事实、推断、可选演绎和外部核验分开书写；对白演绎在台词处标【演绎】，不要用它补充角色未公开的秘密或线索。

## 人设六字段

每个 NPC 一个 H2，标题写编号加实际姓名与身份。六字段固定，顺序不变，字段名不可改：

```markdown
## N002 港务官 哈维尔

- 动机：压住走私账本，保住职位。（p.12）
- 秘密：账本副本藏在钟楼夹层。（p.19）
- 口头禅：按规矩办。
- 弱点：怕火。
- 外貌：灰白鬓角，左手戴一枚磨旧的铜戒。
- 背景：在雾港做了十九年港务官，靠替商会擦账上位。（p.9）
```

| 字段 | 写什么 | 依据要求 |
| --- | --- | --- |
| 动机 | 他想要什么、为什么 | 原文行为可推，或有明写 |
| 秘密 | 他瞒着什么 | 只在原文确有秘密时写；没有就写「原文未设秘密」 |
| 口头禅 | 一句话，能直接念 | 有原话优先引原话 |
| 弱点 | 性格缺陷或可利用之处 | 有原文行为支持 |
| 外貌 | 只写看得见的：体貌、穿着、神态 | 不得混入性格判断与心理活动 |
| 背景 | 来历、履历 | 原文提多少写多少 |

行尾可以写页码便于回查；不确定就不写，别编假来源。未具名角色（酒馆老板、卫兵队长）也要立条目，标题写「N004 酒馆老板（未具名）」。

## 五场景台词

人设文档里每个 NPC 另起一节，写五类场景的口语台词：

```markdown
### N002 台词

- 谈判：规矩写在这儿，你自己看。
- 战斗：卫兵！码头有人闹事。
- 欺骗：账本早烧了，你翻也白翻。
- 求助：帮我按住那盏灯，别让它灭。
- 闲聊：雾港的雾，一年比一年重。
```

规矩：

- 一到两句，带语气，能直接念。不解释规则，不写舞台指示。
- **原文没有对白，不等于不能写。** 只要六字段里已有动机、身份或口头禅依据，就按这个人会怎么说话写一到两句，行尾标【演绎】。整节写满【待补】等于这个功能没做——带团时你仍然得临场编。
- 只有连身份都没交代的背景群众（酒馆里某位客人），才整节跳过并写明原因。
- **不得透露未公开信息**：秘密、动机、隐藏身份、未触发的线索，一律不能从嘴里说出来。
- 原文有原话的，优先引用或改写原话，只顺口吻不加信息。
- 该 NPC 不可能进入某场景就跳过，并在本节末尾写一行原因，例如「（平民，无战斗与欺骗场景）」。

## 形态外貌

一个 NPC 有多个形态（变形、伪装、不同时期），在同一 H2 下列 `### N002 哈维尔 · 客观外貌 · 形态名`，每节写完整独立的外貌段落。

- 纯外貌：只写看得见的。判断句（「看起来阴险」「似乎很紧张」）一律换成可见的动作与表情。
- 每种形态都要能在原文找到依据。原文没写形态，不许凭性格或立绘编。
- 初次登场与常态互动各写一段可朗读描写，供现场直接念。
- 立绘与对应形态的人设、状态互校，冲突时以原文为准。

## 怪物两份汇总

- `怪物数据.md`：属性、HP、AC、攻击、豁免、传奇动作、挑战等级。数值照抄原文，不改不换算。
- `怪物描述.md`：客观外貌、行为方式、战术习惯、出现环境。只写原文支持的。

怪物数据与 S 场景遭遇双向引用；场景里出现的怪物必须在数据文档有条目，反之亦然。

**外部怪物数据**：仅当用户明确提出【调查dnd怪物数据】时，从 https://5e.kiwee.top/ 查找并核验规则版本，标注「外部资料 + 链接 + 版本 + 核验日期」；模组对怪物的特殊改动必须保留。没有匹配或无法访问时记【待补】，不编数值。其他规则系统不套用该站数据。

## 不写这些

- 原文没有的性格分析、童年创伤、隐藏身世。
- 「如果玩家……他会……」的分支推演（那是带团文档的事）。
- 整理文字时擅自生成或重设计立绘。用户明确要求补图时，可按已核实的外貌使用可用绘图工具；将新增设计与原文事实分开标注，且不凭图像推断新形态或能力。
- 把秘密写进朗读段。

## 交付前自查

- 六个字段是否都有内容或明确的【待补】？
- 台词里有没有一句泄露了秘密或未触发的线索？
- 外貌字段有没有出现判断词？
- 每个已确认形态是否都有独立外貌段？
- 场景里提到的每个 NPC 与怪物，数据文档里是否有对应编号？

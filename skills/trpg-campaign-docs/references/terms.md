# 术语与可念性

两件事分开做：先用台账把写法统一，再按可念性标准写口播稿。前者是机械的，后者是判断。

## 术语台账

### 什么时候登记

同一概念在原文出现两种以上写法就登记：

- 音译与意译并存：艾尔夫／精灵，杜瓦夫／矮人，秘银／银铁
- 人名前后不一：哈维尔／哈维、艾琳娜／伊莲娜
- 组织与地名：雾港议会／雾港评议会
- 规则术语：`advantage` 译成「优势／有利」两种

### 登记规则

- `--group` 写概念，`--from` 写要消灭的旧写法，`--to` 写全文统一采用的写法。
- 采用哪种看原文出现频率与用户指定的译本。两者冲突时问用户；不问就按高频，并在总索引记录决定。
- 一条旧写法只能登记一次。要换目标写法，先 `undo`，再重新 `add`。
- 带数字的术语（`+1 长剑`、`3 级法术`）替换前后数字必须相同，否则脚本拒绝。

### 作用范围

台账覆盖各产物的正文及现有白板的文字节点。用 `apply` 预演再加 `--write` 落盘。更新术语表用 `export`。

`[[旧名称#标题|旧译]]` 只改 `旧译`，没有别名的双链和嵌入保留原样。`[旧译](文件.md#标题)` 只改方括号里的显示文字。代码块、行内代码、前置 YAML、标题与块锚点、总索引的实体名称、白板文件节点路径以及 `模组/原文/` 受保护。确需给实体更名时，单独同步标题、索引名称和链接目标。

### 不许替换

- 原文刻意区分两个概念时（「精灵」与「高等精灵」是不同族群），不能合并。
- 玩家自创称呼、角色卡已固定写法、模组专有代号。
- 引号内的原文台词，除非用户要求统一口音与译名。

## 可念性：写 CG 时就要守的规矩

这一节不是「写完再改」的清单，是**下笔时就按这个写**。扫描器 `terms.py scan` 只用来事后抽查。

| 症状 | 下笔时怎么写 |
| --- | --- |
| 被动套被动（「被……所……」） | 写主动句；施动者未知名就写「有人」「众人」，或不写 |
| 长定语（「的……的……」） | 拆成两句，先主体后修饰 |
| 名词化（「进行了一次检查」） | 用动词：「检查了一遍」 |
| 「当……的时候」 | 「……时」，或直接删 |
| 「在……的情况下」 | 「若……」「于是……」 |
| 「从……的角度来看」 | 直接陈述；叙述者不可见就别写 |
| 填充副词（事实上、基本上、某种程度上） | 删 |
| 「是……之一」 | 写具体排名或数量 |
| 「作为一个……」 | 删，或改「身为」 |

**长度**：念出来的句子不超过 40 字；一段朗读控制在三句以内。超了就断句，但**不要改变事实顺序**——先发生的先写。

## 文化隐喻与名物

- **比喻**：保留意象，换成本地读者能感到的对应物；换不掉就改成直接描写感受。
- **文化名物**（弥撒、清教徒、决斗、驿马车、煤气灯）：默认**保留**，它们是模组的世界质感；只在会造成误解时加半句说明。
- **英文习语直译**（一石二鸟、达摩克利斯之剑、潘多拉魔盒）：先判断原文是否真在用这个典故。是，保留并保证上下文够；不是，按字面重写。
- **度量与钱币**：换算会改数字，属禁止项。确需换算，另起一行写「约合」，原文数字保留。

## 纪律

1. 一次只处理一类问题：先把术语收干净，再动笔写 CG。
2. 写完一章用 `check_campaign.py --chapter` 核对本章范围，最后全模组验收时检查术语台账残留。
3. 拿不准的写法保留原文，登记 Q 编号，不硬改。
4. CG 里出现原文没有的事实、动机、秘密、能力、线索，一律退回——这是硬规则，不是风格偏好。
